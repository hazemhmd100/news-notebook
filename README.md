# موجز — مفكرة أخبار عربية خاصة

نسخة أولى HTML/CSS/JavaScript، تعمل محلياً الآن، مع مسار نشر سحابي باستخدام Supabase Free وواجهة ثابتة على Cloudflare Pages Free. **لم تُنشر ولم يُختبر تسجيل الدخول السحابي في حساب فعلي**؛ يلزم إعداد حساب المالك والمفاتيح العامة أولاً.

## ابدأ محلياً

1. ثبّت Node.js 22 أو أحدث.
2. افتح `start.cmd` على Windows، ثم افتح `http://127.0.0.1:5173` واترك نافذة التشغيل مفتوحة. أول تشغيل يحتاج إنترنت لتنزيل المكتبات.
3. اختر «فتح المفكرة المحلية»، ثم «المصادر والأقسام». تبدأ المفكرة بلا مصادر محفوظة.
4. أضف مصدراً مقترحاً، أو أضف «مصدر تجريبي محلي» لاختبار خبرين تدريبيين دون إنترنت.
5. ارجع إلى «مفكرة اليوم»، اختر المصادر، واضغط «اجلب الأخبار ولخّصها». حدد الأخبار التي تريد حفظها أو تصديرها.

بديل الأوامر:

```sh
npm ci
npm start
```

التجربة المحلية **ليست حساباً آمناً متعدد المستخدمين**. الخادم يستمع إلى عنوان الجهاز المحلي فقط، ولا تفتحه على الشبكة العامة. الحفظ في `.local/notebook.json` على هذا الجهاز. لا توجد مزامنة للهاتف في هذا الوضع. ملفات الحالة غير مضمنة في حزمة التسليم. النتائج غير المؤرشفة تعيش في ذاكرة الصفحة وتختفي بعد إعادة تحميلها.

## ما تعمل عليه النسخة

- واجهة عربية RTL للهاتف والحاسوب، ووضع فاتح/داكن.
- دخول بريد/كلمة مرور أو Google عبر Supabase عند إعداد السحابة. لا تسجيل عام داخل الواجهة: المفكرة لمالك واحد.
- إضافة/تعديل/تعطيل/حذف مصادر وأقسام، مصدر واحد أو حتى خمسة مصادر لكل دفعة.
- RSS للمصادر المدعومة، وتحويل بعض روابط صفحاتها الرئيسية إلى التغذية تلقائياً.
- قراءة نص المقال ثم اختيار 4–6 جمل كاملة منه، عادة خمس جمل؛ كل جملة فقرة مستقلة. عدد الأسطر المرئية يتغير حسب عرض الشاشة.
- تلخيص استخلاصي حتمي دون أي API ذكاء اصطناعي، ولا حساب أو مفتاح لخدمة توليد مدفوعة.
- حد 20 خبراً مختلفاً لُخّص بنجاح يومياً. يفحصه الخادم وتثبته معاملة قاعدة بيانات؛ يتجدد في 00:00 UTC.
- فشل الجلب/النص القصير لا يستهلك الرصيد. إعادة نفس الرابط في اليوم نفسه لا تضيف وحدة. عند بلوغ 20 يتوقف التلخيص حتى اليوم التالي.
- تقدم ومراحل وأخطاء مع متابعة بقية الأخبار، وإيقاف بعد الخبر الجاري.
- استبدال/إضافة نتائج مع منع تكرار الروابط؛ حفظ الأخبار المحددة فقط، وبحث وترشيح وترتيب زمني في الأرشيف.
- TXT عربي UTF-8 وملف DOCX فعلي، ونسخ النص. PDF عبر مربع الطباعة في المتصفح: اختر **Save as PDF / حفظ كـPDF**. لا يرفع التصدير نصوصك إلى خدمة خارجية.

## المصادر وحدود MVP

المسموح حالياً BBC عربي والجزيرة وأخبار الأمم المتحدة، مع روابط RSS للقسم المطلوب. هناك قائمة نطاقات مقيدة على الخادم لمنع جلب عناوين داخلية أو غير موثوقة؛ **إضافة أي موقع عشوائي ليست مدعومة بعد**. روابط الصفحات الفرعية العادية التي لا تحتوي RSS قد تفشل، وعندها يلزم رابط تغذية القسم. لا نتجاوز حجباً أو اشتراكاً أو حماية ناشر. بعض الصفحات الديناميكية/المحجوبة أو القصيرة تفشل ويظهر سبب الفشل.

الملخص استخلاصي، وليس كتابة تحليلية أو ترجمة أو ضماناً لدقة المصدر. لا يدمج أخباراً متشابهة موضوعياً ولا يرتب بحسب أهمية تحريرية. اختيار لغة ترجمة ومحرك تلخيص محلي/إنترنت وتجميع الموضوعات من الاتفاق الأوسع مؤجلة إلى ما بعد هذه النسخة؛ لا توجد أزرار شكلية توهم بتفعيلها. لغة الملخص هي لغة النص الأصلي. حفظ/تصدير الملخص مع رابط المصدر يساعد على الرجوع للسياق.

العدد لكل مصدر يبقى خاضعاً لسقف الدفعة 20 وللرصيد المتبقي. استبدال نتائج الشاشة لا يمس الأرشيف. تعرض السحابة أحدث 1000 خبر مؤرشف في النسخة الأولى؛ صدّر الأرشيف واحذف ما لا تحتاجه دورياً. حذف مصدر لا يحذف أخباره المؤرشفة.

## إعداد Supabase المجاني

1. أنشئ مشروعاً في مؤسسة **Free**، دون ترقية أو تفعيل إضافات مدفوعة. لا تضف وسيلة دفع لهذا المشروع إذا أردت منع احتمال تفعيل خطة مدفوعة من لوحة الحساب.
2. افتح SQL Editor ونفذ `supabase/migrations/202610080001_notebook.sql` مرة واحدة. السكربت ينشئ الجداول ويغلق وصول المتصفح المباشر إليها؛ كل البيانات تمر عبر الخادم الذي يتحقق من المالك.
3. في Authentication → Users أنشئ مستخدم المالك ببريده الحقيقي وكلمة مرور قوية، مع تأكيد البريد إدارياً للحساب الخاص. احتفظ بمعرّف UUID. لا نحتاج إرسال بريد مدفوع لإنشاء الحساب الخاص بهذه الطريقة.
4. جهّز عنوان الواجهة النهائي المجاني على Pages كما في القسم التالي. في Authentication → URL Configuration اضبط Site URL وعناوين Redirect المسموحة بدقة. أضف عنوان localhost فقط إن كنت تختبر السحابة محلياً.
5. ثبّت Supabase CLI بالطريقة الرسمية، ثم نفذ من مجلد المشروع:

```sh
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase functions deploy notebook
```

ملف `supabase/config.toml` يضبط وظيفة notebook مع تحقق JWT داخل المعالج؛ يرسل المعالج الرمز إلى Auth `/user` ويتحقق من `OWNER_USER_ID`. لا تغيّر ذلك إلى وثوق بمعرّف يرسله المتصفح.

6. في Edge Functions → Secrets أضف:

```text
OWNER_USER_ID = UUID المستخدم المالك
ALLOWED_ORIGINS = https://YOUR_PROJECT.pages.dev
```

يمكن فصل أكثر من origin بفاصلة، دون `/` في النهاية. `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` يوفرهما Supabase داخل الوظيفة تلقائياً. **لا تضع service_role في الواجهة أو ملف يبدأ بـVITE_ أو Git**.

7. انسخ `.env.example` إلى `.env.local` محلياً واضبط القيم العامة:

```text
VITE_SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY
VITE_API_URL=https://YOUR_PROJECT_REF.supabase.co/functions/v1/notebook
```

أعد تشغيل التطوير أو أعد البناء بعد تعديلها. هذه القيم العامة تظهر في ملفات المتصفح بحكم التصميم. لا ترسل كلمات المرور أو المفاتيح السرية في المحادثات.

## Google والدخول بالبريد

في Google Cloud Console أنشئ OAuth Web client، واضبط شاشة الموافقة وحساب الاختبار إن كان التطبيق في Testing. أضف رابط callback الذي يعرضه Supabase، عادة `https://YOUR_PROJECT_REF.supabase.co/auth/v1/callback`، إلى Authorized redirect URIs. فعّل Google في Supabase وأدخل Client ID/Secret هناك فقط.

استخدم نفس البريد المؤكد للمالك في Google ليُربط بحسابه وفق آلية ربط الهويات في Supabase، ثم تحقق أن UUID نفسه. **أي UUID آخر مرفوض من الخادم حتى إن نجح OAuth**. يمكن إيقاف التسجيل العام بعد تهيئة الهوية؛ راجع إعدادات إنشاء المستخدمين عند تجربة Google لأول مرة. الواجهة تستخدم PKCE. تسجيل Google لا يحتاج API توليد مدفوع.

إرسال البريد الافتراضي في Supabase محدود بعناوين الفريق وبمعدل منخفض، وليس خدمة بريد إنتاجية عامة. النسخة لا تدعي توفير استعادة كلمة مرور جاهزة؛ يمكن لمالك المشروع تغييرها إدارياً. إذا أضفت SMTP لاحقاً فتحقق من مجانيته وحدوده أولاً؛ لا يوجد SMTP مدفوع ضمن هذا المشروع.

## نشر الواجهة مجاناً

اختر Cloudflare **Pages Free** لموقع ثابت، دون Workers مدفوعة أو نطاق خاص مدفوع:

```sh
npm ci
npm run build
```

في لوحة Cloudflare → Workers & Pages → Create → Pages → Direct Upload، ارفع **محتويات `dist` فقط**، وعيّن اسماً لتحصل على `https://NAME.pages.dev`. لا ترفع `.env.local` أو `.local` أو المشروع كله. يمكن حجز الاسم أولاً ثم إعادة رفع build بعد ضبط URL في Supabase. في خيار Git ضع build command `npm run build` وoutput `dist` ومتغيرات VITE العامة في إعداد البناء.

الواجهة الثابتة نفسها تعرض شاشة دخول للعامة؛ المحتوى الخاص محمي بخادم المالك وقواعد قاعدة البيانات. لا يوجد أي سر أو أرشيف مضمّن في الملفات الثابتة. لا تنشر build غير مهيأ وتتوقع أن تعمل `/api` المحلية على Pages.

**النشر لم يُنفَّذ هنا** لعدم وجود مشروع Supabase أو ربط حساب نشر ومفاتيح مهيأة في الجلسة. مسار التسليم مجاني موثق، ولا ننشئ خدمة استضافة أخرى مجهولة التكلفة.

## تحقق بعد النشر

1. افتح الموقع على هاتف وحاسوب وسجّل الدخول بالبريد، ثم Google، وتحقق أن الأرشيف نفسه ظاهر.
2. في نافذة خاصة يجب ألا يظهر المحتوى قبل الدخول. جرّب حساباً مختلفاً: يجب أن يرفض الخادم الوصول (403).
3. أضف مصدرين، اجلب خبراً من كل مصدر، واحفظ واحداً فقط؛ بعد تحديث الصفحة يبقى المحدد وحده في الأرشيف.
4. افحص `/health` ثم تأكد أن `/state` بلا رمز يرجع 401. لا تعتبر health دليلاً على اكتمال المصادقة.
5. اختبر بلوغ 20 وعدم تجاوزها من تبويبين. الاختبارات المحلية تغطي منطق المعاملة، لكن تحقق الاستضافة الفعلي مطلوب أيضاً.
6. صدّر العربية إلى TXT/DOCX وPDF وراجع ترتيبها على جهازك. استخدم browser Print → Save as PDF؛ شكل الخطوط قد يختلف حسب النظام.

## منع التكلفة والقيود المجانية

لا توجد أي استدعاءات لـOpenAI أو Gemini أو أي خدمة توليد/ترجمة مدفوعة، ولا مسار تلقائي للترقية. الاتصالات الخارجية هي مصادر الأخبار وSupabase Auth/Database فقط. الحد 20 قاعدة تطبيق وليس حد فوترة عام لكل عمليات الحساب؛ احتفظ بمشروعي الاستضافة وقاعدة البيانات على Free. لا يستطيع التطبيق منع تغيير خطة حسابك من لوحة المزود.

بحسب صفحات المزود التي روجعت في 8 أكتوبر 2026: Supabase Free يتضمن قاعدة بيانات 500MB و50,000 مستخدم نشط شهرياً و500,000 استدعاء Edge Function. المشروعات المجانية قد تتوقف بعد عدم النشاط. وظيفة Free لها 150 ثانية wall time و2 ثانية CPU و256MB ذاكرة. التطبيق يجلب مقالاً واحداً لكل طلب ويحد حجم الصفحة إلى 1.5MB والمهلة إلى 15 ثانية؛ قد تتوقف الخدمة عند حدود المزود بدلاً من ضمان توافر دائم. راجع القيم الحالية قبل النشر.

## التطوير والاختبارات

```sh
npm test
npm run build
npm audit
```

`src/` للواجهة والتصدير، `supabase/functions/_shared/` لمنطق الجلب والتلخيص والتحقق، `supabase/functions/notebook/` لربط السحابة، `server/` للتجربة المحلية، و`tests/` لاختبارات الحالات المهمة. تشمل الاختبارات معاملة PostgreSQL الفعلية داخل PGlite، لا تمثيلاً برمجياً للعداد فقط. ملفات lock تثبت إصدارات المكتبات. راجع `VERIFICATION.md` لمعرفة ما اختُبر وما لم يُختبر.
